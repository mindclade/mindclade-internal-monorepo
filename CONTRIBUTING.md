# Contributing

- Follow `AGENTS.md` and the dependency direction in
  `docs/architecture/dependency-law.md`.
- Add public behavior through typed contracts and focused tests.
- Keep CPU tests offline and fast. Mark accelerator and distributed tests explicitly.
- Do not add model weights, generated datasets, credentials, or environment-specific
  paths to version control.
- Releases are package-specific, protected, and internal-only.
