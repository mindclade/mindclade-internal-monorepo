# CladeFold Q0

CladeFold Q0 is the random-initialized reference implementation of the
Mindclade token/pair/atom model contract. It combines a masked pairformer trunk
with a proper-rotation-equivariant atom denoiser and deterministic VE sampling.

Q0 is for software, numerical, packaging, and serving qualification only. It is
not trained, biologically validated, clinically suitable, or production
qualified.
